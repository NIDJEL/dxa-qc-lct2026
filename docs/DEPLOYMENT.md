# Deployment

Инструкция сервера, Compose, Nginx, healthcheck и расположение закрытых весов: [deploy/README_DEPLOY.md](../deploy/README_DEPLOY.md). Dockerfile копирует только код и закреплённые зависимости; медицинские данные и веса в образ не включены. Веса монтируются read-only, загрузки размещаются в tmpfs. CLI остаётся доступен через override entrypoint или [run_container.sh](../run_container.sh).

До публикации требуется полный тест финального образа без сети: одна и несколько групп, `Dataset_test` только как loader check, повреждённые и неподдерживаемые файлы, повторный inference, CSV/JSON и Web API. Для целевой конфигурации нужны новые замеры cold/warm, RAM/VRAM и успешных файлов; исторические цифры использовать нельзя.

На 2026-09-29 локальный Docker daemon не отвечает. Уточнённый сервер `31.77.11.129` доступен по SSH, но имеет 1 vCPU, 1,9 ГБ RAM, без GPU и swap; Docker не установлен, Nginx и другие сервисы уже работают. Эти ресурсы недостаточны для проверенного полного inference с базовыми весами около 3,7 ГБ. Сборка и deployment не заявляются успешными.
