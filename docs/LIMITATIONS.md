# Ограничения

- Обучающие официальные метки относятся к исходным исследованиям, а не к отдельным снимкам. Независимой экспертной DXA image-level валидации нет.
- DINO/MI2 router E023 показал 42 ошибки hip→spine на 208 внешних бедренных рентгенограммах; перенос на DXA не доказан. Вероятность и abstention не калиброваны для клинического решения.
- Правая и левая сторона бедра не подтверждены из DICOM; официальная укладка/ротация остаётся единой меткой.
- E007 MIL выдаёт общий вектор для study-bag. Singleton inference меняет решения и не подтверждён как отдельная модель.
- Поддержан audited single-frame, 2-D, uint8, MONOCHROME2. Неподдерживаемые DICOM возвращают ошибку.
- DICOM spacing часто отсутствует; внешняя калибровка конкретного сканера не переносится на произвольное устройство. Нет валидированных landmarks или контуров для физических измерений.
- Failure/unknown и смешанные пакеты CSV нуждаются в подтверждённом evaluator организаторов. До этого нельзя утверждать полную конкурсную совместимость.
- Финальная Docker сборка, серверный CPU/GPU benchmark и публичный end-to-end smoke ещё не подтверждены.
