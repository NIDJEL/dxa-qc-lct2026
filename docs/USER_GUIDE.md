# Руководство пользователя

1. Откройте веб-интерфейс DXA QC и загрузите один DICOM, несколько файлов либо папку. На публичном стенде используйте только обезличенные данные.
2. Нажмите «Начать анализ». Прогресс отражает чтение DICOM и обработку групп.
3. На обзорном экране смотрите по снимкам анатомическую область, quality-head и отмеченные нарушения. Откройте карточку для вероятностей и исходного изображения.
4. Скачайте CSV для восьмипольного результата и JSON для ошибок, provenance и подробных оценок. Экспериментальный singleton режим отключает официальный CSV.
5. При ошибке файла прочитайте JSON; корректные независимые группы в web-режиме продолжают анализ.

Модельные оценки требуют проверки специалистом. Один study-level вектор E007 может повторяться у нескольких изображений одного исследования; нельзя трактовать эти строки как независимую image-level валидацию.
